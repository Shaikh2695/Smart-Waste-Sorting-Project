Smart Waste Sorting Machine

Clean • Smart • Automated

Automatic Waste Management System

Segregates waste into Dry, Wet & Metal using smart technology.

About Project

Smart Waste Sorting Machine is an innovative system designed to reduce human effort and increase recycling efficiency by automatically sorting waste.

How It Works

Step 1

Waste is inserted into the machine.

Step 2

Sensors detect type of waste.

Step 3

Waste is sorted automatically.

Waste Categories

Wet Waste

Food waste, vegetables, fruits

Dry Waste

Paper, plastic, cardboard

Metal Waste

Iron, aluminium, cans

Benefits

  • Reduces pollution
  • Saves time & manpower
  • Encourages recycling
  • Smart & eco-friendly
