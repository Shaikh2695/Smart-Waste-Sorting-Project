Smart Waste Sorting Machine

Project Details & Technology

Machine Components

IR Sensor (Infraraed Sensor)

Detects object presence on the conveyot belt to start the system automatically.

Moisture Sensor

Identifies wet and dry waste for proper segregation into bins.

Metal Sensor

Detects metallic objects to separate metal waste for recycling.

Motor & Conveyor

Moves waste automatically along the conveyor belt to the appropriate bins.

Sensors Used

The system uses smart sensors to analyze waste type. Based on sensor output, waste is diverted into the correct bin automatically.
