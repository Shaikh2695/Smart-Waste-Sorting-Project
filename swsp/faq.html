Frequently Asked Questions

Q1. What is Smart Waste Sorting Machine?

It is an automated system that segregates waste into wet, dry and metal categories.

Q2. Which sensors are used?

IR sensor, moisture sensor and metal sensor are used.

Q3. Is this project eco-friendly?

Yes, it reduces pollution and increases recycling efficiency.

Q4. Can this be used in real life?

Yes, it can be implemented in smart cities, colleges and public places.
